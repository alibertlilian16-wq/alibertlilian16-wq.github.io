# Portfolio de Lilian Alibert

Site personnel : parcours, projets et CV à télécharger.
En ligne sur https://alibertlilian16-wq.github.io/

## Contenu

- `index.html`, `style.css`, `main.js` : le site, sans framework ni dépendance.
- `cv/` : les trois CV en PDF (général, agence, promotion).
- `img/` : portrait, image d'aperçu pour les réseaux, icône.
- `fonts/` : Bricolage Grotesque et Newsreader, hébergées sur le site (licence OFL), pour ne charger aucune ressource externe.

## Liens par profil

Le sélecteur « Vous recrutez pour » change le CV proposé et l'adresse de la page :

- https://alibertlilian16-wq.github.io/?pour=agence
- https://alibertlilian16-wq.github.io/?pour=promoteur

Le QR code de chaque CV pointe vers la version qui lui correspond.

## Mettre à jour un CV

Remplacer le PDF dans `cv/` en gardant le même nom de fichier, puis publier.
